# Testing Assignment Service

## Tujuan

Dokumentasi ini digunakan untuk mencatat proses pengujian API Assignment Service.

## Persiapan

1. Pastikan PHP telah terinstal.
2. Jalankan Assignment Service dari direktori service.
3. Siapkan koleksi Postman yang tersedia di folder `postman/`.
4. Pastikan data awal pada folder `data/` tersedia.

## Pengujian

Pengujian API dilakukan menggunakan koleksi Postman dan script pengujian pada folder `tests/`.

Pengujian yang perlu dilakukan:

- Pemeriksaan endpoint health, jika tersedia.
- Pengambilan data assignment.
- Penambahan assignment.
- Validasi request.
- Pengubahan data, jika endpoint tersedia.
- Penghapusan data, jika endpoint tersedia.
- Pengujian request yang tidak valid.

## Hasil Pengujian

Hasil pengujian aktual dan bukti pelaksanaan dicatat setelah pengujian dilakukan. Dokumentasi ini tidak menyatakan bahwa seluruh pengujian telah berhasil sebelum pengujian dilaksanakan.
